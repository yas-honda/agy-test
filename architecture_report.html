Section 02

ゲームステートマシン (State Machine)

TITLE → INSTRUCTIONS → PLAYING → BOSS_WARNING → BOSS_BATTLE → STAGE_CLEAR → ALL_CLEAR の 7 状態遷移。 残機ゼロで GAMEOVER ループ、無限コンティニュー対応。

Section 05

ボス当たり判定設計 (Hitbox Architecture)

各ボスはコア (弱点) と外殻装甲 (シェル) の二層構造。弾丸はコアに命中した場合のみ HPを削り、装甲に当たった場合はヒットフラッシュのみ発生。

graph LR B["Player Bullet 💥"] --> CHK{命中判定} CHK -->|"Boss 1 のみ\n軌道シールドに接触"| SH["🛡 Orbit Shield\nhp -= damage\nシールド破壊チェック"] CHK -->|"blockedByShield = false"| CORE{"Core Box\n衝突?"} CORE -->|YES| VUL{"isCoreVulnerable()\n?"} VUL -->|TRUE| DMG["boss.hp -= damage\n⚡ Hit Flash RED\n画面シェイク"] VUL -->|"FALSE\n(Boss3 パネル閉)\"| SHELL_FLASH["⚪ Hit Flash WHITE\n装甲跳弾"] CORE -->|NO| SHELL{"Shell Parts\n衝突?"} SHELL -->|YES| SHELL_FLASH SHELL -->|NO| MISS["💨 Miss"] DMG -->|"boss.hp <= 0"| DEAD["🎆 Boss Defeated\nboss.dead = true"]
Section 06
